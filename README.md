# Github Issues Tracker

This GitHub Issues Tracker is a streamlined web dashboard that integrates with a RESTful API to monitor development tasks in real-time. Built with Asynchronous JavaScript (Async/Await) and Tailwind CSS, the application ensures a smooth, non-blocking user experience with a fully responsive UI and dynamic, data-driven styling.


## Questions & Answers

### 1. What is the difference between var, let, and const?
- **`var`**: Old way to declare variables. It can be redeclared and updated.
- **`let`**: Modern way. It can be updated but not redeclared in the same scope.
- **`const`**: Used for values that should not change. It cannot be updated or redeclared.


### 2. What is the spread operator (...)?
**`spread operator (...)`**: The spread operator (...) is used to expand or copy elements of an array or object.

Example:
const newArray = [...oldArray];

It helps to copy or combine arrays/objects easily.

### 3. What is the difference between map(), filter(), and forEach()?
- **`map()`**: Creates a new array by changing each element.
- **`filter()`**: Creates a new array with only selected elements.
- **`forEach()`**: Loops through elements but does not return a new array.
### 4. What is an arrow function?
**`arrow function`**: An arrow function is a short and modern way to write functions in JavaScript.

Example:
const add = (a, b) => a + b;

It makes the code shorter and cleaner.

### 5. What are template literals?
 **`template literals`**: Template literals are used to write strings with variables easily using backticks `.

Example:
const name = "John";
Hello, my name is ${name}

They make string formatting easier.
